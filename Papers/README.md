# Manuscript versions

The manuscript is archived by version so that every formalization and review
record can be matched to the exact mathematical text it concerns.

- [`v1`](v1/) is the manuscript version corresponding to the Palomar
  formalization and the initial Palomar submission.
- Subsequent human-edited revisions will be added as `v2`, `v3`, and so on.
- A manuscript will be labeled **Final Version** only after it has been fully
  edited and revised by humans.

Earlier version directories are retained unchanged when a new version is
added.
